Pearls & Palms is a responsive React-based web application designed to centralize information about beach festivals, cultural events, and commercial activities in Mangalore, Karnataka. It allows users to explore upcoming events, register and book tickets, discover beach attractions, and view event schedules through an interactive calendar. The app includes user authentication (frontend-only), an admin dashboard for event management, a reviews and ratings system, and a search bar for quick access to events—all styled using React-Bootstrap, Bootstrap, HTML, and CSS.
